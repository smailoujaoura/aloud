PDFs

A PDF in a tab has no text an extension can reach — Chrome renders it in a plugin and Firefox in its own viewer — so Aloud opens PDFs in a reader of its own. Click the toolbar button on a PDF and it appears there automatically; on Firefox, and on Chrome without Allow access to file URLs, local files have to be chosen by hand. A PDF on a website has to be downloaded from that site, so Aloud asks for permission for that one site the first time you open a PDF there.

The original pages keep figures, tables and columns, and the sentence is highlighted on the page itself. Reflowed text is easier on a small screen and follows the page’s text size, but loses the document’s appearance.

In the original pages, select text to highlight, underline or strike it through, or to add a note — keys H U S N, and 1–4 for colours. Marks are kept on this device as you go; Save writes them into the PDF as standard annotations any viewer shows. On Chrome, a PDF opened with the button below is saved straight back into the same file; elsewhere Save asks where to put it, and choosing the original replaces it.

Highlights & notes

Highlight text on any page to keep it — with your note and tags — in the Library, and see it highlighted again whenever you come back.

Select text and press Alt+Shift+S, or right-click → Highlight and keep in Notes, on any page. Your highlights show on a page when you use Aloud there, when you open a note from the Library, or by themselves on the sites below.

Video & audio speed

Aloud’s other job: set the speed of any video or audio on a page — from the keyboard, without the site’s own menu.

Press Alt+Shift+V on a page to start it there; Aloud asks for nothing in advance. Sites you add below start it by themselves, and each one asks for that site only.

Advanced

This applies when Kokoro runs on the CPU. On the GPU it always loads the full-precision model (~320 MB, downloaded once), because that is the build with complete WebGPU coverage.

Make Kokoro fast on Firefox (about:config)

Firefox has WebGPU, but ships it switched off — and switches it off separately for web workers, which is where Aloud runs synthesis. Turning both on lets Kokoro run on your graphics card: measured on a machine that did it, it went from roughly three times slower than real time to faster than Piper.

    Then restart Firefox and press Check for a GPU again. The first GPU run downloads Kokoro's full-precision model (~320 MB) once.

    These are experimental settings. If Firefox misbehaves afterwards — crashes, blank pages, heavy battery use — set the same prefs back to false and Aloud goes back to the CPU path on its own.

    Aloud remembers where you stopped on each page and PDF, on this device only, and picks up there next time.
